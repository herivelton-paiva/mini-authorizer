# Mini-autorizador de cartões

Este é um projeto Spring Boot 4.1 que implementa um mini-autorizador de cartões para transações de Vale Refeição e Vale Alimentação.

## 📋 Pré-requisitos

- Java 21
- Maven 3.6+

## 🚀 Como executar

### Executar com Docker
```bash
docker-compose up
```

### Executar localmente
```bash
mvn spring-boot:run
```
